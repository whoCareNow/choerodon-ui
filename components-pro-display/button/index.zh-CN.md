无 DataSet 依赖的 Pro 风格按钮，适用于静态展示与受控 `onClick`。

## API

| 属性 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| color | 颜色风格 | `default` `primary` `secondary` 等 | `default` |
| funcType | 展现模式 | `flat` `raised` `link` | `raised` |
| loading | 加载状态 | boolean | - |
| icon | 图标 type | string | - |
| disabled | 禁用 | boolean | - |
| onClick | 点击回调 | function | - |

不支持 `dataSet`、`name` 及表单提交联动。
