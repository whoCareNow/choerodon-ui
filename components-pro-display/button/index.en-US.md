Pro-styled button without DataSet for static display and controlled `onClick`.

## API

| Property | Description | Type | Default |
| --- | --- | --- | --- |
| color | Color style | string | `default` |
| funcType | Display mode | `flat` `raised` `link` | `raised` |
| loading | Loading state | boolean | - |
| icon | Icon type | string | - |
| disabled | Disabled | boolean | - |
| onClick | Click handler | function | - |

No `dataSet`, `name`, or submit binding.
